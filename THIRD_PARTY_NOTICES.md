# Source and dependencies

This independent app was developed for Ross Gates. Audio conversion and Apple Speech integration were adapted from his existing Live Scorecard project. Those source files contain no third-party copyright or license notices; the app does not vendor an external implementation or package dependency.

The build links Apple's macOS frameworks and the system SQLite library. Those components remain subject to their own terms and are not redistributed in the app archive. OpenAI services require the installer's own API account and key; the MIT license covers this project's source, not access to those services.

The distributed call examples are synthetic. Real customer transcripts, developer keys, local databases, and API response diagnostics are excluded from the repository and release artifacts.
